1. OBJECT-ORIENTED PROGRAMMING (OOP) PRINCIPLES
================================================

A. ENCAPSULATION (Data Hiding)
   └─ Private variables + Public methods to access them
   └─ Example from Task.java:
      private String taskName;        // Hidden from outside
      public String getTaskName() {   // Accessed through method
          return taskName;
      }
   └─ Why? Protects data and allows controlled access

B. ABSTRACTION (Hiding Complexity)
   └─ Show only essential details, hide implementation
   └─ Example: TaskManager.addTask() hides how tasks are stored
   └─ User doesn't need to know it uses ArrayList

C. COMPOSITION (Using Objects Within Objects)
   └─ MainUI class contains TaskManager and TimerManager objects
   └─ private TaskManager taskManager;
   └─ This "has-a" relationship is composition

D. POLYMORPHISM (Multiple Forms)
   └─ Overloaded constructors in Task class:
      public Task(int id, String name) { ... }              // 2 params
      public Task(int id, String name, String date, ...) { ... }  // 4 params
   └─ Same method name, different parameters


2. COLLECTIONS - ArrayList USAGE
==================================

What is ArrayList?
└─ Resizable array - grows as you add items
└─ Better than fixed-size arrays for variable amounts of data

In TaskManager.java:
   private List<Task> tasks;
   tasks = new ArrayList<>();
   tasks.add(newTask);        // Add task
   tasks.remove(index);       // Delete task
   tasks.get(index);          // Get specific task

Why ArrayList?
└─ Don't need to know size beforehand
└─ Automatic resizing
└─ Easy to add/remove items


3. JAVA SWING GUI COMPONENTS
=============================

Main Components Used:

A. JFrame
   └─ Main window container
   └─ frame = new JFrame("Window Title");
   └─ Set size, visibility, close behavior

B. JPanel
   └─ Container for grouping components
   └─ Used for layout organization
   └─ Can have different layout managers (BorderLayout, GridLayout, etc.)

C. JButton
   └─ Clickable buttons
   └─ button.addActionListener(e -> doSomething());

D. JLabel
   └─ Display text/information
   └─ JLabel label = new JLabel("Some text");

E. JTextField
   └─ Input field for user text
   └─ String input = textField.getText();

F. JList
   └─ Display list of items
   └─ DefaultListModel for managing list items
   └─ JScrollPane for scrolling

G. Timer (javax.swing.Timer)
   └─ Executes code at regular intervals
   └─ swingTimer = new Timer(1000, e -> updateUI());
   └─ 1000ms = 1 second


4. LAYOUT MANAGERS
==================

BorderLayout
   └─ regions: NORTH, SOUTH, EAST, WEST, CENTER
   └─ Used for dividing screen into major sections
   └─ panel.add(topPanel, BorderLayout.NORTH);

GridLayout
   └─ Arranges components in grid (rows x columns)
   └─ new GridLayout(3, 1) = 3 rows, 1 column
   └─ All cells equal size

FlowLayout
   └─ Places components left to right, top to bottom
   └─ Wraps to next line when space runs out


5. EVENT HANDLING (Button Clicks)
==================================

Pattern:
   button.addActionListener(new ActionListener() {
       public void actionPerformed(ActionEvent e) {
           // Code to run when button clicked
       }
   });

Lambda Expression (Modern Way):
   button.addActionListener(e -> methodToRun());

In this project:
   addButton.addActionListener(e -> addTaskAction());
   deleteButton.addActionListener(e -> deleteTaskAction());

8. FLOW OF THE APPLICATION
============================

When you run "java MainUI":

1. MainUI constructor is called
2. Creates frame (JFrame) 
3. Initializes TaskManager and TimerManager
4. Calls setupUI() to create all GUI components
5. Adds panels and buttons to frame
6. Sets frame visible
7. App waits for user interactions

When user clicks a button:
1. ActionListener is triggered
2. Corresponding method (e.g., addTaskAction()) is called
3. Logic runs (add/delete/update task)
4. updateTaskListDisplay() refreshes the UI
5. Frame redraws with updated information

Timer updates:
1. Swing Timer fires every 1000ms (1 second)
2. Calls timerManager.tick() to decrease time
3. Updates timerDisplay label with new time
4. When timer reaches 0, alert is shown

10. USEFUL TIPS FOR BEGINNERS
==============================

A. Debugging:
   • Add System.out.println() to trace execution
   • Check if variables have expected values
   • Use try-catch for error handling

B. GUI Design:
   • Keep layout simple and organized
   • Use proper spacing (EmptyBorder for padding)
   • Use consistent fonts and colors
   • Test with different screen sizes

C. Code Organization:
   • One class per file (.java file)
   • Use meaningful variable names
   • Comment complex logic
   • Keep methods short (Single Responsibility Principle)

D. Testing:
   • Test each feature individually
   • Try edge cases (empty inputs, maximum values)
   • Check if all buttons work
   • Verify data persists in list

E. Common Mistakes to Avoid:
   • Forgetting semi-colons
   • Wrong capitalization (Java is case-sensitive)
   • Modifying list while iterating
   • Not parsing String to int/other types
   • Accessing UI components from wrong thread
