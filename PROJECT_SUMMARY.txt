HOW THE APPLICATION WORKS:
──────────────────────────

1. STARTUP:
   └─ User runs: java MainUI
   └─ MainUI creates instances of TaskManager and TimerManager
   └─ GUI components are set up and displayed

2. TASK MANAGEMENT FLOW:
   User Input → ActionListener triggered → Corresponding method called
   → TaskManager updates task list → UI refreshes with updateTaskListDisplay()

3. TIMER FLOW:
   User clicks Start → Swing Timer starts → tick() called every 1 second
   → UI updated with remaining time → When time reaches 0, alert shows

4. DATA STORAGE:
   └─ Uses ArrayList (in-memory storage only)
   └─ Data is lost when application closes
   └─ Could be extended with file I/O for persistence
