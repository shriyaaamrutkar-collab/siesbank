✓ No external dependencies needed


FILES INCLUDED:
---------------
1. Task.java          - Task data model
2. TaskManager.java   - Task management logic
3. TimerManager.java  - Timer logic
4. MainUI.java        - GUI interface (main entry point)
5. README.txt         - Detailed documentation


WHAT EACH CLASS DOES (Quick Summary):
--------------------------------------

Task.java
• Stores info about a single task
• Properties: taskId, taskName, dueDate, isCompleted
• Methods: getters, setters, toString()

TaskManager.java
• Manages collection of Task objects
• Methods: addTask(), deleteTask(), markTaskCompleted(), etc.
• Uses ArrayList internally

TimerManager.java
• Implements Pomodoro timer (25 minutes)
• Methods: startTimer(), stopTimer(), resetTimer(), tick()
• Tracks remaining time

MainUI.java
• Creates the complete GUI
• Uses Java Swing components
• Connects to TaskManager and TimerManager
• Has all button event handlers


OOP CONCEPTS USED:
------------------
1. Encapsulation - Private variables with public getters/setters
2. Abstraction - Complex logic hidden in classes
3. Composition - MainUI "uses" TaskManager and TimerManager
4. Polymorphism - Overloaded constructors
